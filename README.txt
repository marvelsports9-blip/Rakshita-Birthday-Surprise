# Rakshita Birthday Surprise Website

A mobile-first interactive birthday website made for Rakshita.

## Included
- Interactive gift → secret PIN (2002) → curtain reveal → birthday → memories → balloons → scratch card → letter → final wish.
- 6 uploaded photos are already included and optimized.
- English-only website copy.
- Krishna blessing theme mixed with the dark/pink/gold cinematic style from the reference screenshots.
- No text captions are placed underneath the photos.

## Add the song
For the requested "Dooron Dooron Unplugged" music, place your legally obtained/authorized MP3 file here:

assets/dooron-dooron-unplugged.mp3

The website already points to that filename. The music button is at the top-right.

## Free hosting
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Enable GitHub Pages from the repository's Pages settings.
4. Open the generated Pages URL and share it.

You can also deploy the same folder on Cloudflare Pages.

## Important
The birthday date is set for 22 August 2026 and the page presents her age as 24.
